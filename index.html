¿Qué es Embarcadero Dev-C++?

Embarcadero Dev-C++ es un entorno de desarrollo integrado (IDE) para programar en C y C++. Reúne herramientas para escribir, compilar y depurar código.

Es una versión mejorada de Bloodshed Dev-C++ y Orwell Dev-C++. Utiliza MinGW/GCC como compilador y está desarrollado con Embarcadero Delphi.

También puede utilizarse con Cygwin u otros compiladores basados en GCC. Al ser una aplicación nativa de Windows, tiene un consumo reducido de memoria.

Características Principales

  • Compilador TDM-GCC 9.2.0 para 32 y 64 bits.
  • Compatibilidad con compiladores basados en GCC.
  • Depuración integrada con GDB.
  • Análisis de rendimiento con GPROF.
  • Administrador de proyectos.
  • Resaltado de sintaxis personalizable.
  • Navegador de clases y lista de funciones.
  • Completado de código.
  • Formato de código con AStyle.
  • Creación de bibliotecas estáticas y DLL.
  • Plantillas para crear proyectos.
  • Creación de archivos Makefile.
  • Compilación de archivos de recursos.
  • Administrador de herramientas y extensiones Devpak.
  • Impresión, búsqueda y reemplazo de texto.

¿Cómo comenzar a programar?

  1. Instalar y abrir Embarcadero Dev-C++.
  2. Crear un archivo fuente o un proyecto de C o C++.
  3. Escribir y guardar el código.
  4. Compilar y corregir los errores indicados.
  5. Ejecutar el programa y comprobar su resultado.

¿Cómo funciona Embarcadero Dev-C++?

Dev-C++ reúne herramientas para escribir, compilar, ejecutar y depurar programas en C y C++ desde un mismo entorno.

Del código al programa

  1. Escribir: crear el código fuente en el editor. El resaltado de sintaxis ayuda a distinguir sus elementos.
  2. Guardar: almacenar el archivo con la extensión correspondiente, como .cpp para un archivo de C++.
  3. Compilar: utilizar el compilador para traducir el código. Si encuentra errores, revisar los mensajes y corregirlos.
  4. Ejecutar: iniciar el programa generado y comprobar sus resultados.
  5. Depurar: investigar el comportamiento del programa para localizar problemas en su funcionamiento.

Herramientas del entorno

Editor de código
Permite escribir y modificar las instrucciones del programa.
Compilador
Traduce el código fuente como parte de la generación del ejecutable.
Depurador
Permite seguir la ejecución e inspeccionar valores para investigar errores.
Administrador de proyectos
Organiza los archivos que forman parte de un programa.

Compilar no garantiza un resultado correcto

Un programa puede compilar y aun así producir resultados equivocados. Por eso es necesario ejecutarlo con diferentes datos y comprobar que responde como se espera.
